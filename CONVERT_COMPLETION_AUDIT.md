## Security and dependency check

The production dependency audit, re-run after the final code change, reports **0 high, 0 critical, and 34 moderate advisories**. Remaining moderates flow through current Privy/EVM wallet packages and the Solana `jayson` chain. The unpatched `bigint-buffer` native-binding issue is replaced via npm override with `apps/web/vendor/bigint-buffer`, a bounded JavaScript compatibility module. `toml` and `ws` are overridden to patched releases. `npm audit fix --force` suggests breaking downgrades of Orca and Privy and is not a valid remedy for this release. Recheck advisories before deployment.

They used public onchain addresses only to request/simulate unsigned transactions. No signature was produced, no transaction was submitted, and no user's funds were touched.
- Local `http://localhost:5173/api/health` and `/api/quotes` returned expected mainnet status and three live venues after the latest server restart. A 0.01 SOL/USDC quote returned Jupiter, direct Raydium, and direct Orca routes with distinct live outputs and no provider failures.
